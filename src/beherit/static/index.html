Instrukcja Obsługi i Przewodnik Beherit

v0.3.0

Oficjalny, kompleksowy przewodnik po platformie autonomicznych agentów AI. Poznaj sposób podłączania silników SDK i kluczy API, architekturę Markdown-First, bazę wiedzy RAG, integrację z n8n oraz szczegółowy słownik funkcji aplikacji.

⚡

1. Szybki Start — Jak utworzyć i uruchomić agenta w 3 krokach

Podstawowa ścieżka wdrożenia agenta od zera do pierwszej autonomicznej akcji.

1

Kreator Agenta

Kliknij przycisk + Nowy Agent w górnym pasku. Podaj nazwę (np. Analityk Finansowy), wybierz silnik SDK (np. Google Antigravity) oraz preferowany model LLM (np. gemini-3.8-flash).

2

Podłączenie Uwierzytelnienia

W sekcji Połączenie Agenta kliknij przycisk „Użyj sesji z serwera” (darmowe tokeny z subskrypcji CLI) lub wklej bezpośredni klucz API. Przetestuj łączność i kliknij Utwórz Agenta.

3

Interakcja i Raporty

Kliknij 💬 Czat, aby rozmawiać w czasie rzeczywistym z podglądem myśli, lub kliknij ⚡ Uruchom, aby wykonać zadanie autonomiczne i wygenerować raport w zakładce Raporty.

🔑

2. Jak Podłączyć Agenta — Uwierzytelnianie SDK i Klucze API

Zasada izolacji sesji per agent, różnica między subskrypcją a kluczem API oraz procedury logowania.

💡 Dlaczego warto łączyć agentów przez Subskrypcję SDK (Zero API Token Costs)?

W przeciwieństwie do tradycyjnych frameworków agentowych naliczających opłaty za każdy token wejściowy i wyjściowy, Beherit potrafi wykorzystać Twoje aktywne subskrypcje desktopowe (Antigravity CLI, Claude Pro/Team). Dzięki temu możesz uruchamiać nielimitowane audyty i konwersacje bez ponoszenia dodatkowych kosztów API.

🟢 Google Antigravity SDK

Domyślny

Oficjalne środowisko agentowe Google DeepMind. Obsługuje modele Gemini 3.8 Flash, Pro oraz Claude 3.7 Sonnet w ramach subskrypcji.

Sposoby podłączenia:
  • 1-Klik Import z Hosta: Kliknij przycisk „Użyj sesji z serwera”. Beherit sklonuje plik ~/.gemini/antigravity-cli/.credentials.json do katalogu agenta.
  • Klucz Google Gemini API: Wygeneruj darmowy lub płatny klucz w Google AI Studio (AIzaSy...) i wklej w pole tokena.

🟠 Claude Code SDK

Anthropic

Środowisko agentowe Anthropic bazujące na subskrypcjach Claude Pro/Team lub bezpośrednim API Messages.

Sposoby podłączenia:
  • Subskrypcja Pro/Team: Po zalogowaniu claude na hoście, kliknij „Użyj sesji z serwera” (wykrywa plik ~/.claude/.credentials.json).
  • Klucz Anthropic API: Wygeneruj klucz w Anthropic Console (sk-ant-...) i wklej w formularzu agenta.

🔵 OpenAI & Lokalne LLM

OpenAI / Ollama

Obsługa modeli OpenAI (GPT-4o, o3-mini) oraz całkowicie lokalnych modeli uruchamianych przez instancję Ollama.

Sposoby podłączenia:
  • OpenAI API: Utwórz klucz w OpenAI Platform (sk-...).
  • Lokalne Ollama: Uruchom Ollama na serwerze i kliknij przycisk „🔄” (Odśwież modele) — Beherit pobierze lokalne modele bez wysyłania danych do chmury.

🛡️ Izolacja Sesji i Diagnostyka Połączenia (Auth Healthcheck)

Każdy agent posiada własny folder .auth/session.json z restrykcyjnymi uprawnieniami systemowymi chmod 0600. Dzięki temu wygaśnięcie subskrypcji jednego agenta nie ma wpływu na pozostałych. Przycisk „Przetestuj połączenie” wykonuje natychmiastowy test walidacyjny struktury tokena i czasu wygaśnięcia, prezentując status kolorową odznaką: 🟢 Połączono, 🟡 Wygasła lub 🔴 Niepołączony.

3. Przegląd Możliwości i Architektura Beherit

Poznaj zaawansowane mechanizmy platformy: Markdown-first, hybrydowy RAG, Multi-Cron, MCP i piaskownicę.

📝 Filozofia Markdown-First & Obsidian

Agenci nie są zamknięci w relacyjnej bazie danych. Każdy agent to zwykły katalog zawierający plik agent.md (YAML + Master Prompt) oraz instructions.md. Konfigurując zmienną BEHERIT_AGENTS_DIR w .env, możesz zarządzać agentami bezpośrednio z poziomu notatek w sejfie Obsidian.

💬 Czat SSE, Myśli Modelu i Anulowanie (Abort)

Strumieniowanie odpowiedzi w czasie rzeczywistym przez Server-Sent Events (SSE). Wewnętrzny proces myślowy modelu trafia do zwijanego akordeonu „Myśli modelu”. W trakcie generowania dostępny jest czerwony przycisk Zatrzymaj, który natychmiast wysyła sygnał przerwania SIGKILL do procesu i zachowuje fragment odpowiedzi w SQLite.

⏰ Wielozadaniowy Harmonogram (Multi-Cron)

Jeden agent może realizować wiele różnych zadań cyklicznych w tle (np. poranny audyt o 08:00 i wieczorny raport o 20:00). Każde zadanie posiada własny prompt i ścieżkę pliku docelowego. Rozwijany przycisk ⚡ Uruchom pozwala na natychmiastowe doraźne uruchomienie wybranego zadania lub wpisanie promptu ad-hoc.

📚 Lokalny Hybrydowy RAG (Baza Wiedzy)

Wyszukiwarka semantyczna w SQLite FTS5 z algorytmem rankingowym BM25. Beherit dzieli pliki z folderu knowledge/ na akapity i wstrzykuje do zapytania wyłącznie najbardziej pasujące fragmenty. Obsługuje dokumenty Markdown, PDF (z biblioteką pypdf), obrazy z podglądem oraz linki WWW i wideo YouTube (z autodetekcją metadanych oEmbed).

🖼️ Multimodalne Raporty i Artefakty

Gdy agent wygeneruje wykres, obrazek, wideo lub plik z danymi w podkatalogu roboczym, system automatycznie wykrywa nowy plik, rejestruje go jako artefakt zadania i osadza interaktywny podgląd w raporcie Markdown oraz w tabeli historii audytów.

🛡️ Piaskownica Narzędzi & Wbudowany Serwer MCP

Trzy poziomy ochrony terminala bash: Piaskownica (Restricted) — twarda blokada ucieczek .. i wrażliwych katalogów systemowych, Pełna swoboda (Unrestricted) oraz Wyłączony. Beherit udostępnia narzędzia agenta jako oficjalny serwer Model Context Protocol (beherit mcp --agent-slug).

Master Prompt (System Prompt) Główny prompt definiujący tożsamość, cel główny i zasady rozumowania agenta, zapisywany w pliku agent.md.
Wytyczne Operacyjne Szczegółowe instrukcje behawioralne, reguły formatowania tabel Markdown i procedury krok po kroku zapisywane w pliku instructions.md.
Klocki MCP & Edytor JSON Pozwala dodać serwery Model Context Protocol (Brave Search, PostgreSQL, SQLite, Filesystem, GitHub, Puppeteer, Fetch) i edytować ich konfigurację JSON.
Harmonogram Multi-Cron Konfiguracja nielimitowanych zadań cyklicznych w tle (`ScheduledJob`), zdefiniowanie wyrażenia cron, dedykowanego promptu oraz pliku docelowego.

💬 Elementy Okna Czatu i Raportów:

Selektor Wątków w Czacie:

Umożliwia przełączanie się między niezależnymi sesjami dialogowymi z agentem lub otworzenie czystego wątku przyciskiem „+ Nowy Wątek” bez utraty poprzedniej historii.

Zwijany Akordeon Myśli (*Thinking*):

Pozwala podejrzeć, w jaki sposób model analizował zadanie i jakie kroki zaplanował, bez zaśmiecania ostatecznej treści odpowiedzi.

Przycisk Zatrzymaj (Stop / Abort):

Wysyła sygnał przerwania procesu do aktywnego CLI, natychmiast kończąc strumień i trwale zapisując dotychczas odebrany fragment odpowiedzi.

Przycisk 📄 Raport w Tabeli Historii:

Otwiera okno renderujące sformatowaną treść zapisanego raportu Markdown wraz z nagłówkami, tabelami, wykresami i pobranymi artefaktami.

5. Automatyzacja i Integracja z n8n oraz Zewnętrznymi Webhookami

Steruj agentami Beherit ze swoich przepływów n8n, zapisuj wyniki w Obsidianie i odbieraj callbacki.

Każdy agent Beherit posiada dedykowany uniwersalny endpoint webhooka: POST /api/agents/{slug}/run. Umożliwia on zdalne uruchomienie agenta z zewnętrznego systemu (n8n, cron, curl), przekazanie dowolnego kontekstu JSON, zapisanie wyniku do konkretnego pliku w skarbcu Obsidian oraz wysłanie zwrotnego powiadomienia (callbacku).

Parametr JSON Typ Opis i przeznaczenie
prompt string Instrukcja lub pytanie dla agenta (opcjonalne — domyślnie używa promptu agenta).
context object Dowolne dane strukturalne (np. payload z webhooka sklepu, błąd z potoku danych, dane użytkownika).
destination_file string Ścieżka do pliku w skarbcu Obsidian, w którym ma zostać zapisany wynik (np. Raporty/Status.md).
file_mode string "overwrite" (nadpisuje treść) lub "append" (dopisuje na końcu pliku — idealne dla dzienników).
save_report boolean Czy wygenerować oficjalny raport audytowy w folderze reports/ i zapisać w historii SQLite.
callback_url string Adres URL webhooka n8n, na który Beherit wyśle zapytanie POST po zakończeniu przetwarzania.
async_execution boolean Gdy true, endpoint natychmiast odpowiada 200 OK {"async": true}, a agent pracuje w tle.
Przykładowe polecenie cURL do uruchomienia agenta: 
curl -X POST "http://100.121.196.113:8650/api/agents/analityk-rynkow/run" \
     -H "Content-Type: application/json" \
     -d '{
       "prompt": "Przeanalizuj dzisiejszy raport sprzedaży",
       "context": {"transakcje": 142, "obrot": 18500},
       "destination_file": "Raporty/Sprzedaz-Dziś.md",
       "file_mode": "overwrite",
       "save_report": true
     }'

6. Narzędzia MCP i Piaskownica Uprawnień (Sandbox)

Model Context Protocol, integracja zewnętrznych serwerów narzędzi i ochrona systemu.

Beherit wspiera oficjalny standard **Model Context Protocol (MCP)** stworzony przez Anthropic. Agent może nie tylko korzystać z zewnętrznych serwerów MCP, ale sam Beherit udostępnia wbudowany serwer narzędzi piaskownicy: 

beherit mcp --agent-slug analityk-rynkow
🔍 Brave Search MCP:

Umożliwia agentowi wyszukiwanie aktualnych informacji w sieci WWW live przy użyciu oficjalnego klucza Brave Search API.

🐘 PostgreSQL & SQLite MCP:

Udostępnia agentowi możliwość inspekcji schematów tabel i bezpiecznego wykonywania zapytań SQL do wskazanej bazy danych.

📁 Filesystem MCP:

Pozwala na bezpieczny odczyt i zapis plików w wybranych, precyzyjnie zdefiniowanych katalogach roboczych.

🐙 GitHub & Puppeteer MCP:

Pozwala na integrację z repozytoriami GitHub (PR, Issue) oraz rendering stron internetowych przez bezgłową przeglądarkę Chromium.

8. Najczęściej Zadawane Pytania (FAQ) i Rozwiązywanie Problemów

Szybkie odpowiedzi na typowe pytania konfiguracyjne i diagnostyka błędów.

Q: Jak zsynchronizować agentów ze swoim sejfem Obsidian?

Otwórz plik .env w katalogu Beherit i ustaw zmienną BEHERIT_AGENTS_DIR=/sciezka/do/twojego/sejfu/Obsidian/Agenci. Po zrestartowaniu aplikacji wszyscy nowi agenci oraz ich raporty pojawią się bezpośrednio w Twoim skarbcu notatek.

Q: Dlaczego odznaka połączenia agenta świeci się na czerwono lub żółto?

Żółta odznaka oznacza, że sesja wygasła (np. minął czas tokena CLI). Kliknij przycisk 🔑 Klucz na karcie agenta i ponownie wybierz „Użyj sesji z serwera” lub wklej aktualny klucz API, a następnie kliknij „Przetestuj połączenie”.

Q: Jak zabezpieczyć panel kodem PIN przed niepowołanym dostępem?

W pliku .env ustaw zmienną BEHERIT_ACCESS_TOKEN=twoj-tajny-kod-pin. Po restarcie panel wyświetli ekran blokady wymagający podania PINu, a zapytania API bez nagłówka autoryzacji zwrócą kod 401 Unauthorized.

Q: Jak korzystać z Beherit na telefonie iPhone poza domem?

Włącz aplikację Tailscale na telefonie oraz na serwerze Beherit. Wpisz w przeglądarce Safari adres Tailscale serwera z portem 8650 (np. http://100.121.196.113:8650). Następnie wybierz opcję Udostępnij ➔ Do ekranu początkowego, aby uzyskać pełnoekranową aplikację PWA.
